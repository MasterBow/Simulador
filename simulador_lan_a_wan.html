Líneas 1-53
// Algoritmo de Simulación del Funcionamiento de Interconexión LAN a WAN
Inicio
  // Declaración de parámetros lógicos y topológicos
  Definir Subred_LAN_A como "192.168.10.0/24", Gateway_A como "192.168.10.1"
  Definir Subred_LAN_B como "192.168.20.0/24", Gateway_B como "192.168.20.1"
  Definir Enlace_WAN como segmentos IP "10.0.0.1" y "10.0.0.2"
  // Fase 1: Inicialización física y enlace de nodos
  Para cada Nodo_Final en Subred_LAN_A hacer
    Establecer conexión física mediante cable UTP Categoría 6 (norma T568B)
    Configurar parámetros TCP/IP (Dirección IP, Máscara, Puerta de Enlace)
  FinPara
  Conectar puerto uplink del Switch_A hacia la interfaz LAN del Router_A
  Conectar interfaz WAN del Router_A hacia el Router_B mediante infraestructura externa
  // Fase 2: Simulación de transmisión de paquetes extremo a extremo
  Imprimir "Generando paquete de datos en Computadora_A para Computadora_B"
  Paquete = CrearEstructuraTCP(IP_Origen: "192.168.10.10", IP_Destino: "192.168.20.10")
  // Fase 3: Conmutación local en Capa 2
  Computadora_A transmite trama Ethernet hacia Switch_A
  Si IP_Destino pertenece a la misma subred (Subred_LAN_A) Entonces
    Switch_A consulta tabla CAM (direcciones MAC)
    Reenvía trama directamente al puerto del dispositivo receptor
  Sino
    // Traspaso obligatorio a Capa 3 debido a distinta subred
    Switch_A canaliza trama hacia Router_A (Gateway_A)
  FinSi
  // Fase 4: Enrutamiento de Capa 3 (Sede de Origen)
  Router_A recibe trama; desencapsula encabezado de Capa 2
  Analiza IP_Destino ("192.168.20.10") consultando tabla de enrutamiento
  Si ruta hacia Subred_LAN_B existe Entonces
    Encapsula paquete con protocolo WAN (PPP / HDLC / Encabezado IP de salto)
    Transmitir paquete a través del enlace WAN hacia Router_B (Siguiente salto: "10.0.0.2")
  Sino
    Descartar paquete; emitir mensaje ICMP de destino inalcanzable
    Terminar Proceso
  FinSi
  // Fase 5: Tránsito por la Nube WAN y Recepción en Sede Destino
  Router_B intercepta paquete proveniente del enlace WAN
  Router_B desencapsula formato WAN; examina dirección IP de destino
  Consulta tabla topológica local; identifica conexión directa a Subred_LAN_B
  Envía trama hacia Switch_B mediante interfaz LAN asignada
  // Fase 6: Entrega final en Capa 2 remota
  Switch_B recibe trama; analiza dirección MAC receptora en tabla CAM
  Transfiere trama al puerto físico vinculado a Computadora_B
  Computadora_B procesa información recibida exitosamente
  Imprimir "Comunicación completada satisfactoriamente entre redes LAN a través de WAN"
Fin
